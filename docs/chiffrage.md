# Chiffrage financier fictif – MyClimbingList

*Dernière mise à jour : 27/11/2026 – Version : 0.2*

## 1. Objectif

Ce document estime ce que coûterait le projet MCL s'il était réalisé par une équipe de professionnels plutôt que par des étudiants. 

## 2. Hypothèses

| Hypothèse | Valeur |
|---|---|
| Équipe | 1 Scrum Master, 1 Product Owner, 2 développeurs |
| Nombre de créneaux de SAE (estimation) | 118 |
| Durée d'un créneau | 1 h 30 |
| Heures par membre | 118 × 1,5 = **177 h** |
| Journée de travail | 7 h |
| Jours par membre | 177 / 7 ≈ **25,3 jours** |
| Périmètre | Uniquement le temps passé sur les créneaux de SAE (hors travail personnel hors créneaux) |
| Charge | Les quatre membres sont comptés avec le même nombre de créneaux |

## 3. Taux journaliers retenus

| Profil | TJ |
|---|---|
| Développeur | 500 € / jour |
| Scrum Master | 600 € / jour |
| Product Owner | 600 € / jour |

## 4. Calcul

| Profil | Personnes | Jours chacun | Taux | Coût |
|---|---|---|---|---|
| Développeur | 2 | 25,3 | 500 € | 25 286 € |
| Scrum Master | 1 | 25,3 | 600 € | 15 171 € |
| Product Owner | 1 | 25,3 | 600 € | 15 171 € |
| **Total** | **4** | | | **55 629 €** |

Le coût du projet, s'il était réalisé par des professionnels, est donc estimé à environ **55 600 €**.

## 6. Ce qui n'est pas compté

- le travail effectué en dehors des créneaux de SAE ;
- les réunions avec le client hors créneaux ;
- les frais de gestion et la marge d'une société de services ;
- l'hébergement, les comptes développeur des stores et les éventuelles licences (voir [informations licences](./MCL-informations-licences-dev.pdf)) ;
- la maintenance après livraison.
