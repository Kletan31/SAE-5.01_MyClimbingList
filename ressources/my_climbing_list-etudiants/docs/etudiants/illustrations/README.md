# Illustrations du guide étudiant

Neuf captures de la démo locale ont été réalisées le 13 septembre 2026, avec le compte fictif `demo.climb`, dans une fenêtre de 430 × 800 pixels. Les données et les plans sont synthétiques. Aucune nouvelle pratique n’a été enregistrée pour les captures. Le PDF et le document Word présentent des extraits cadrés ; les PNG conservent les captures complètes.

Huit schémas pédagogiques accompagnent le guide. Chaque schéma est fourni en PNG et en SVG modifiable. Ils distinguent les mécanismes du POC et les propositions de refonte dans le contexte des chapitres correspondants.
